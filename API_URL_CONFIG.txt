🔴 সবচেয়ে গুরুত্বপূর্ণ ধাপ:

1. আপনার Render Backend URL খুঁজুন
   - Render.com → Backend সার্ভিস → URLs সেকশন
   - এটি এরকম: https://nurulquranmadrasha-backend.onrender.com

2. ফাইলগুলি আপডেট করুন:
   
   ✏️ admin_panel/config.js (লাইন 15)
   ─────────────────────────────────────
   পরিবর্তন করুন:
     return "RENDER_BACKEND_URL";
   
   এটিতে:
     return "https://nurulquranmadrasha-backend.onrender.com";
   
   
   ✏️ frontend/config.js (লাইন 15)
   ─────────────────────────────────────
   পরিবর্তন করুন:
     return "RENDER_BACKEND_URL";
   
   এটিতে:
     return "https://nurulquranmadrasha-backend.onrender.com";

3. গিট কমিট এবং পুশ করুন:
   $ git add admin_panel/config.js frontend/config.js
   $ git commit -m "Fix Render API URL"
   $ git push

4. Vercel এ অপেক্ষা করুন (বিল্ড সম্পন্ন হওয়া পর্যন্ত)

═══════════════════════════════════════════════════════════════════════════════

✅ যাচাইকরণ:

1. ব্রাউজার খুলুন → F12 কনসোল ট্যাব
2. এটি দেখা উচিত:
   [Frontend Config] API_BASE: https://nurulquranmadrasha-backend.onrender.com
   [Admin Config] API_BASE: https://nurulquranmadrasha-backend.onrender.com

3. লগইন করুন → এডমিন প্যানেল যান
4. নতুন ব্যবহারকারী যোগ করার চেষ্টা করুন

═══════════════════════════════════════════════════════════════════════════════

❌ যদি ত্রুটি পান:

"Cannot read properties of undefined (reading 'authFetch')"
→ সম্ভাব্য কারণ: config.js সঠিক নয়
→ সমাধান: উপরের ধাপগুলি পুনরাবৃত্তি করুন

"Cannot reach Backend / 502 Bad Gateway"
→ সম্ভাব্য কারণ: Render Backend সবসময় চলছে না
→ সমাধান: Render.com এ Backend সার্ভিস শুরু করুন

"CORS Error"
→ সম্ভাব্য কারণ: CORS সেটিংস ভুল
→ সমাধান: VERCEL_RENDER_SETUP.md পড়ুন (CORS সেকশন)
