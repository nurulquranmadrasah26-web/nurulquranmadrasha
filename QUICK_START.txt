❓ সাধারণ সমস্যা
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

সমস্যা: "Cannot find module 'express'"
সমাধান: npm install (backend/ ডিরেক্টরিতে থাকুন)

সমস্যা: "Connection refused 127.0.0.1:5000"
সমাধান: ব্যাকএন্ড সার্ভার চলছে কিনা যাচাই করুন (npm start)

সমস্যা: "MongoDB connection failed"
সমাধান: .env এ সঠিক MONGODB_URI এবং নেটওয়ার্ক অ্যাক্সেস

সমস্যা: "CORS error"
সমাধান: .env এর ALLOWED_ORIGINS এ আপনার URL যোগ করুন

সমস্যা: "লগইন ব্যর্থ"
সমাধান: শংসাপত্র যাচাই করুন এবং জেটি_সিক্রেট মেলান
