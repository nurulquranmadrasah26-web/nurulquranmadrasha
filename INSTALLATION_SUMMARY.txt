🚀 দ্রুত শুরু করুন:

1. আর্কাইভ এক্সট্র্যাক্ট করুন:
   tar -xzf nurulquranmadrasha-fixed.tar.gz
   cd v0-project

2. Backend সেটআপ করুন:
   cd backend
   cp ../.env.example .env.local
   # এডিট করুন এবং MONGODB_URI, JWT_SECRET সেট করুন

3. Backend চালু করুন:
   npm install
   npm start

4. Frontend চালু করুন (নতুন টার্মিনালে):
   cd frontend
   python -m http.server 8000

5. লগইন করুন:
   http://localhost:8000
   আইডি: admin
   পাসওয়ার্ড: changeme123

6. নতুন ব্যবহারকারী যোগ করুন:
   এডমিন প্যানেল > ব্যবহারকারী > নতুন ব্যবহারকারী
