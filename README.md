# নুরুল কোরআন মাদরাসা — সম্পূর্ণ ব্যবস্থাপনা সিস্টেম

এটি একটি সম্পূর্ণ শিক্ষা প্রতিষ্ঠান ব্যবস্থাপনা সিস্টেম যা শিক্ষার্থী, স্টাফ, ফি, পরীক্ষা, রুটিন এবং আরও অনেক কিছু পরিচালনা করে।

## 📋 প্রকল্প গঠন

```
├── frontend/           # ফ্রন্টএন্ড ওয়েবসাইট (index.html)
├── admin_panel/        # এডমিন ড্যাশবোর্ড (admin.html)
├── backend/            # Express API সার্ভার (Node.js)
├── .env.example        # Environment variables উদাহরণ
└── README.md           # এই ফাইল
```

## 🚀 দ্রুত শুরু করুন

### ১. প্রাথমিক সেটআপ

```bash
# ফাইলগুলি ডাউনলোড করুন
cd nurulquranmadrasha

# Backend dependencies ইনস্টল করুন
cd backend
npm install

# ফ্রন্টএন্ড ফাইলগুলি স্থানীয়ভাবে পরিবেশন করুন
cd ../frontend
python -m http.server 8000
```

### ২. Environment Variables সেটআপ করুন

`.env.example` থেকে একটি নতুন ফাইল তৈরি করুন:

```bash
cp .env.example .env.local
```

এবং নিচের মান গুলি পূরণ করুন:

- **MONGODB_URI**: আপনার MongoDB সংযোগ স্ট্রিং
- **JWT_SECRET**: একটি র্যান্ডম সিক্রেট (নিচে দেখুন)
- **CLOUDINARY_***: Cloudinary কনফিগ (ছবি আপলোডের জন্য)

#### JWT_SECRET তৈরি করুন:

```bash
openssl rand -base64 32
```

উৎপন্ন স্ট্রিং `.env.local` এ পেস্ট করুন।

### ৩. Backend চালু করুন

```bash
cd backend
npm start          # উৎপাদন মোড
# অথবা
npm run dev        # উন্নয়ন মোড (auto-reload)
```

সার্ভার এখন `http://localhost:5000` এ চলছে।

### ৪. প্রথম লগইন

ব্রাউজার এ খোলুন: `http://localhost:8000`

**লগইন করুন** (প্রথম সুপার এডমিন):
- **আইডি**: `admin`
- **পাসওয়ার্ড**: `changeme123`

**নোট**: প্রথম লগইনের পরে পাসওয়ার্ড পরিবর্তন করুন।

## 🎯 API কনফিগ (উৎপাদন এর জন্য)

### Frontend এবং Admin Panel

ফাইলগুলি এডিট করুন:
- `frontend/config.js`
- `admin_panel/config.js`

```javascript
// Production API URL সেট করুন
var PRODUCTION_API = "https://your-api-server.com";
```

### Backend CORS সেটআপ

`.env.local` এ যোগ করুন:

```
ALLOWED_ORIGINS=https://yoursite.com,https://admin.yoursite.com
```

## 🛠️ ট্রাবলশুটিং

### "সার্ভারের সাথে সংযোগ করা যায়নি"

**কারণ**: API URL সঠিক নয় বা সার্ভার চলছে না।

**সমাধান**:
1. Backend চলছে কিনা যাচাই করুন: `http://localhost:5000`
2. `config.js` এ API_BASE সঠিক কিনা চেক করুন
3. ব্রাউজার Console (F12) এ error দেখুন

### "অ্যাকাউন্ট নিষ্ক্রিয়"

সুপার এডমিন প্যানেল থেকে ব্যবহারকারী সক্রিয় করুন।

### ছবি আপলোড ব্যর্থ

Cloudinary কনফিগ যাচাই করুন (.env.local এ)।
